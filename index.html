Tabs

Use a real button or link before reaching for ARIA. ARIA only adds meaning; it adds no behavior.

Arrow keys move between tabs, Home and End jump to the first and last, and Tab moves into the panel.

Check with keyboard only, then NVDA or VoiceOver, then run axe.

Dialog
